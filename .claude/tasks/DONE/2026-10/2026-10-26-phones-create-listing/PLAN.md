### Risks
- `CurrentUser` uses `DbSession`: on `POST /phones` the auth session stays open during the LLM calls unless the endpoint avoids `DbSession` for writes. With `scope="function"` the connection is held until the endpoint returns. Accepted: one pooled connection per request, read only. Writes go only through `run_in_transaction`.
- Supabase may lack the HNSW `vector_cosine_ops` on old pgvector (<0.5). Supabase ships >=0.7.
- `alembic check` and the `vector` type / HNSW index: autogenerate compares types; the model declares the same index so no diff.
- `Numeric` `display_size` returns `Decimal`: schema serializes as a number (Frontend `z.coerce.number`).
- Frontend Regex and Backend Regex can drift: one test table with the same cases on both sides.
